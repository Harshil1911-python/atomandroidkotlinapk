# Atom Bills – Android APK (ready to use)

Complete offline billing app. All pages from atomdemo2 are already inside `app/src/main/assets/`.

## Get the APK (GitHub only)

1. Create a **new empty** GitHub repository.
2. Unzip this project.
3. Drag **all files and folders** into the empty repo → Commit.
4. Open the **Actions** tab → wait for **Build Atom Bills APK**.
5. Download the **AtomBills-APK** artifact → install the `.apk` on your phone.

No extra files to add. Billing opens automatically.

## What’s included

- Billing (main screen)
- Calculator
- Proprietor
- Accountant
- Full IndexedDB offline storage
- Icons, logos, sounds, CSS, JS
